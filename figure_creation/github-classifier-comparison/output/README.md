## Interpretation

- The default input is `ids_repos.llm_accepted.csv`, the comparison-oriented accepted output. Missing rows are labelled `not_accepted`; that means absent from this accepted list, not necessarily confirmed excluded by an incomplete LLM run.
- `01b_repository_overlap_map_*.svg` is the direct set-overlap view: every dot is one repository in the exact keyword-only, LLM-only, both-accept, both-exclude, or LLM-uncertain set. It deliberately has no numeric axes.
- `01c_repository_profile_pca_*.svg` reduces repository descriptions/topics and both classifiers' labels to two PCA dimensions. Nearby points have similar overall profiles; the PCA axes do not have a standalone semantic meaning.
- To compare all evaluated decisions rather than accepted sets, explicitly pass `ids_repos.llm_classified.csv` with `--llm`.
- Family matrices use only repositories accepted by both approaches.
- `classifier_outliers.csv` is the audit table for decision mismatches, family mismatches, and LLM uncertainty.
- Method labels are LLM outputs, not ground truth. Compare model runs with the pairwise figures when more than one `--llm` input is supplied.
